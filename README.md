# Tudu

A task management app with list and Kanban board views.

## Features

- Task management with list and Kanban board views
- User authentication (login/signup)
- Dashboard with overview

## Tech Stack

- Next.js 16
- Supabase (auth & database)
- TypeScript

## Getting Started

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Environment

Requires Supabase credentials in `.env.local`.
